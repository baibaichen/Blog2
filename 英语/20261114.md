## 五、易混词与记忆提示

1. **passive / active / dominant**
   - **passive**：被动的，强调不主动行动或参与。
   - **active**：主动的；积极参与的，与 passive 相对。
   - **dominant**：占主导地位的，强调控制力或影响力，不只是“积极”。

2. **minor / mild**
   - **minor**：强调程度、规模或重要性较小，如 **a minor injury**（轻伤）。
   - **mild**：强调不强烈、不严重，如 **mild symptoms**（轻微症状）、**a mild disease**（轻症疾病）。

3. **vital / essential / significant**
   - **vital**：至关重要，缺少它可能严重影响结果。
   - **essential**：必不可少，强调必要性。
   - **significant**：重要的或显著的，不一定表示“不可缺少”。

4. **insurance / insurer / payer**
   - **insurance**：保险，是制度或服务。
   - **insurer**：保险公司；承保人。
   - **payer**：支付方，不一定是保险公司，也可能是政府或个人。

5. **词形联想**
   - **prevent → preventable**：预防 → 可预防的。
   - **effect → effective → ineffective**：效果 → 有效的 → 无效的。
   - **require → requirement**：要求 → 要求；必要条件。
   - **purchase → purchaser**：购买 → 购买者。
